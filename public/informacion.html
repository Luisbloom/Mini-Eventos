03 / EQUIDAD

Reparto de roles

El azar no debería decidir la tabla

Se intentará que todos los participantes tengan aproximadamente las mismas oportunidades de jugar como impostor. Siempre que el número de jugadores y partidas lo permita, el reparto será equilibrado.

5 partidas×2 impostores=10 plazas
Ejemplo con 10 jugadores: cada persona podría jugar exactamente una partida como impostor. No es una condición fija.

04 / PUNTOS

Sistema de puntuación

La clasificación es individual. Estos valores llegan directamente del motor que calcula el leaderboard.

¿POR QUÉ ES INDIVIDUAL?

Mismo equipo, distinta puntuación

Dos jugadores pueden ganar juntos y terminar con diferente puntuación según su actuación.

JUGADOR AVictoria impostor +—2 kills +—Total —
JUGADOR BVictoria impostor +—0 kills +0Total —
✕
DUDA FRECUENTE

¿Qué pasa si me matan al principio?

Morir pronto no elimina tus posibilidades. Como fantasma puedes completar tareas y, si gana la tripulación, mantienes los puntos de victoria.

Victoria+—Todas las tareas+—TOTAL —
No se conceden puntos adicionales por sobrevivir: morir pronto no implica necesariamente haber jugado peor.

Acciones que no dan puntos

SobrevivirReportar cadáveresAcertar una acusaciónVotar correctamenteProvocar una expulsiónRealizar sabotajes

Pueden registrarse como estadísticas, pero no afectan directamente a la clasificación.

05 / TECNOLOGÍA

Registro automático

Las puntuaciones no se introducen manualmente. El host registra la partida con EHR y el Tournament Reporter envía el resultado al servidor de Jartiland cuando termina.

AMONG US↓EHR / REPORTER↓SERVIDOR↓RESULTADO↓PUNTOS↓CLASIFICACIÓN
PARTIDA EN CURSO = DATOS PRIVADOS

La información privada nunca se publica mientras se está jugando. Los datos se envían únicamente después de terminar.

Datos que puede registrar el sistema

RolEquipoVictoria o derrotaKillsTareas completadasTareas totalesVivo / muertoMotivo de muerteAsesinoDuraciónMapa

No todos estos datos otorgan puntos. Algunos sirven únicamente como estadísticas o para revisar un resultado.

06 / JUEGO LIMPIO

Reglas

    DESCONEXIONES Y PROBLEMAS TÉCNICOS

    Cada caso se revisará en contexto

    Una desconexión aislada no implica repetir automáticamente una partida. La organización tendrá en cuenta el momento, el estado de la ronda, cuántos jugadores se vieron afectados y si se puede continuar con normalidad.

    Si el fallo es grave, la partida podrá marcarse como ANULADA y no contará para la clasificación.
